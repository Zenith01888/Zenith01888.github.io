示波器 Web 上位机

Python + Flask + PyVISA · YOKOGAWA DLM2024 / RIGOL / Keysight

这是一个本地运行的示波器采集工具，每秒读取 4 通道共 12 项测量数据，支持实时波形、探头配置、触发设置和 Excel 导出。

  • 厂商自动识别与 SCPI 命令适配
  • 电压趋势 / 频率与幅值 / 时序参数 / 实时波形视图
  • 通道重命名、历史记录与 Excel 导出

GitHub Pages 提供浏览器演示版，方便直接查看界面与交互；连接真实示波器时，请在本机运行 python app.py 后使用。
