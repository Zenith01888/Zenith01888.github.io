# 云上自习室

一个可直接部署到 GitHub Pages 的沉浸式学习陪伴应用，功能参考 Study With Miku 的在线自习室体验。

## 功能

- 番茄钟：专注 / 休息 / 长休息，支持自定义时长与自动切换
- 今日待办：添加、完成、删除，固定一个任务作为当前目标
- 学习数据：今日时长、累计时长、完成轮数、最长专注与最近七天热力图
- 氛围音：雨声、咖啡厅、Lo-fi（Web Audio 合成）与网易云音乐外链播放器
- 沉浸模式：一键隐藏非计时界面，计时环内提供退出入口
- 全屏、本地数据持久化

## 部署

直接访问 `categories/study_room/`，或从主页“工具”下拉菜单打开。数据保存在浏览器 `localStorage` 中，不依赖后端。
